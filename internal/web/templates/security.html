Banned addresses get no response at all. Bans are kept in memory and cleared when the server restarts.

Auto-ban policy

  • An address that fails to log in {{.Threshold}} times within {{dur .Window}} is banned for {{dur .Duration}}.
  • Known SIP scanners (friendly-scanner, SIPVicious and similar) are banned on first contact.
  • Unknown extensions and wrong passwords get the same answer, so scanners can't find valid extensions.

Tune with SIPBX_BAN_THRESHOLD, SIPBX_BAN_WINDOW and SIPBX_BAN_DURATION.
